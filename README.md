## Descricao

Aplicacao web desenvolvida em Angular para apresentar um portal de noticias com categorias, resumo das materias, noticia completa, destaque principal e conteudo exclusivo para assinantes ficticios.

## Funcionalidades

- Exibicao dinamica de noticias declaradas no TypeScript;
- Filtro por categoria;
- Card com resumo, imagem, autor e tempo de leitura;
- Visualizacao da noticia completa por clique;
- Noticia em destaque;
- Conteudo exclusivo bloqueado ou liberado conforme o status do usuario;
- Botao para ativar ou desativar o acesso exclusivo;
- Botao para salvar noticias como favoritas;
- Mensagens condicionais de sucesso, alerta e indisponibilidade;
- Layout responsivo com Flexbox e Grid.

## Tecnologias

- Angular
- TypeScript
- HTML
- CSS

## Como executar

1. Baixe ou clone o repositorio.
2. Execute `npm install`.
3. Execute `ng serve`.
4. Acesse `http://localhost:4200`.
